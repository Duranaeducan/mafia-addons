# Mafia du Mithril — add-ons WoW 3.3.5

Pack d'add-ons réservé aux vendeurs de la guilde. Installation et mises à jour via `MettreAJour.exe` (fourni par le staff).

- `release/version.json` : version courante, lien du zip et empreinte sha256.
- `release/MafiaAddons.zip` : dossiers `Mithril*` à installer dans `Interface\AddOns`.

Ces fichiers sont publiés automatiquement à chaque nouvelle version. Ne pas modifier à la main.
